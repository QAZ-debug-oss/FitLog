FitLog 设计整合更新包（2026-10-30）

部署到 GitHub Pages：将压缩包中的 index.html、sw.js、manifest.webmanifest、icon.svg 和可选的二维码图片上传至 GitHub 仓库根目录，覆盖对应旧文件。不要把 ZIP 文件本身直接作为网页上传。

已包含：四个主导航、多个训练计划与训练日、全动作小尺寸无真人卡通器械示意、动作要点、B站与抖音独立搜索入口、单动作训练、逐组重量次数、组间休息计时、临时增减替换跳过动作、训练总结、训练历史日历、历史编辑、力量趋势、PR、身体及弹跳记录、本地保存、意外中断恢复、PWA 离线基础页面。

数据安全：本版使用 fitlog-v2 本机存储键，不覆盖旧版 fitlog-v1 数据；旧版数据不会自动迁入新版历史。部署前请确认旧版数据已妥善保留。请勿清理 Safari 或浏览器网站数据。

说明：无需登录和云端同步。此版以静态页面与本机 localStorage 为基础，首次需联网打开以安装离线缓存。不同系统的后台计时、声音和振动支持可能不同。旧版捐赠二维码图片仅作为现有资源保留；新版尚未将二维码嵌入页面。
